---

## الخطوة 0 — تحديد الوجهة والتأكد من المستودع

- `تجربة` أو `staging` ← الموقع التجريبي (لا يراه أحد من الناس)
- `حقيقي` أو `production` ← الموقع الحقيقي على الدومين

إن لم يحدد وجهة، اسأله:
> "على وين تنشر؟
> **تجربة** = نسخة خاصة فيك عشان تشوف الشغل قبل ما يشوفه الناس
> **حقيقي** = الموقع اللي يستخدمه الناس فعلًا"

**إن لم يكن هناك مستودع بعيد** (`git remote -v` فارغ)، فهذه أول مرة. اشرح بجملتين
واطلب إذنه، ثم:
```bash
gh repo create <اسم-المشروع> --private --source=. --remote=origin
```
إن لم تكن أداة `gh` مثبّتة، اعرض عليه تثبيتها (`winget install GitHub.cli` أو
`brew install gh`) وتوقّف — ستحتاج إعادة تشغيل التطبيق بعدها.

## الخطوة 1 — الفحص الإلزامي

نفّذ بالترتيب، وتوقّف عند أول فشل:

```bash
cd frontend && npm run check && npm run build
cd backend && ./vendor/bin/pint --test && ./vendor/bin/phpstan analyse && php artisan test
```

ثم تحقق:
- لا يوجد ملف `.env` ضمن المتتبَّع: `git ls-files | grep -E '(^|/)\.env$'` يجب أن يكون فارغًا
- لا توجد كلمات سر أو مفاتيح مكتوبة داخل الكود

**عند أي فشل، توقف فورًا** وقل له بلغة بسيطة:
> "ما قدرت أنشر. في مشكلة: <الشرح بالعربي>. تحب أصلحها؟"

---

## الخطوة 2 — المراجعة الأمنية

شغّل الوكيل `code-reviewer` على التغييرات منذ آخر نشر.
إن كانت النتيجة تحوي أي بند 🔴 **يمنع النشر**، اعرضه عليه بلغة بسيطة وتوقّف.

---

## الخطوة 3 — إن كانت الوجهة "حقيقي"

1. تحقق أن نفس النسخة نُشرت على التجربة وجُرّبت. إن لم تكن، ارفض وقل:
   > "لازم ننشر على التجربة أول وتجرّبها بنفسك. اكتب: `/انشر تجربة`"
2. اطلب منه أن يكتب كلمة **انشر** حرفيًا للتأكيد.
3. لا تتابع قبل أن يكتبها.

---

## الخطوة 4 — التنفيذ

العمل يجري دائمًا على فرع `work`، و `main`/`staging` فرعان على المستودع البعيد فقط —
فلا يقف المستخدم على فرع إصدار أبدًا:

```bash
git push origin work:staging     # تجربة
git push origin work:main        # حقيقي
```

ثم سجّل نقطة النشر — يعتمد عليها `code-reviewer` ليعرف ما الجديد منذ آخر مرة:
```bash
git tag -a "deploy/$(date +%Y%m%d-%H%M)" -m "نشر إلى <الوجهة>"
git push origin --tags
```

راقب سير GitHub Actions حتى ينتهي. إن فشل، اقرأ سجل الخطأ واشرح السبب بلغة بسيطة.

## الخطوة 5 — التسليم

> "تم النشر ✅

>
> افتح الرابط وتأكد من:
> 1. الصفحة تفتح وتسجيل الدخول يشتغل
> 2. آخر شي أضفناه ظاهر
> 3. جرّبه من جوالك كمان
>
> لو في مشكلة، اكتب `/تراجع` وبنرجع للنسخة السابقة فورًا."
