# عقد الخدمات (API Contract)

> هذا الملف هو **المرجع الوحيد**. أي اختلاف بين الشاشات وقاعدة البيانات يُحسم بما هنا.
> يُحدَّث مع كل `/ابن` — والعقد يُكتب **قبل** البناء لا بعده.

المسار الأساسي: `https://api.example.com/api/v1`
المصادقة: ترويسة `Authorization: Bearer <token>`

## سياسة النسخ (Versioning)
- النسخة الحالية: **v1**. كل النقاط أدناه تحتها ما لم يُذكر غير ذلك.
- الواجهة تقرأ رقم النسخة من `API_VERSION` في `src/shared/api/client.ts` — المكان الوحيد.
- **نسخة جديدة فقط عند كسر التوافق** (حذف/إعادة تسمية حقل، تغيير شكل رد). الإضافات تدخل في النسخة الحالية.
- النقاط المنقولة إلى نسخة أعلى تُوثَّق تحت عنوان `### [v2] ...` مع سطر يشرح سبب الكسر.
- حذف نسخة قديمة يُسجَّل هنا بتاريخه بعد موافقة صاحب المشروع.

## الغلاف الموحّد — أربعة مفاتيح دائمًا

كل استجابة، نجاحًا أو فشلًا، لها **نفس المفاتيح الأربعة**. يبنيها
`app/Support/ApiResponse.php` وحده، ويحوّل `bootstrap/app.php` كل استثناء إليها —
فلا يظهر شكل Laravel الافتراضي أبدًا على مسارات `api/*`.

```json
{ "success": true,  "data": {…}, "message": null,  "errors": null }
{ "success": false, "data": null, "message": "…", "errors": { "field": ["…"] } }
```

**شكل `data` له حالتان فقط:**

```json
// عنصر واحد (show · store · update) — الكائن مباشرة
"data": { "id": 1, "name": "…" }

// قائمة (index) — عناصر ومعلومات ترقيم
"data": {
  "items": [ { "id": 1 } ],
  "meta": { "current_page": 1, "last_page": 1, "per_page": 15, "total": 0 }
}
```

`message` نص عربي أو `null`. `errors` غير فارغ في 422 فقط.

## رموز الحالة
`200` نجاح · `201` أُنشئ · `401` غير مسجّل دخول · `403` لا يملك صلاحية · `404` غير موجود · `422` خطأ تحقق · `429` تجاوز حد الطلبات · `500` خطأ خادم

## معاملات القوائم الموحّدة
كل نقطة `index` تقبل: `page` · `per_page` (أقصى 100) · `search` · `sort_by` · `sort_dir` (`asc`/`desc`)
وأعمدة `sort_by` و `search` من قائمة بيضاء يحدّدها كل موديول — ما ليس فيها يُتجاهل.

## المصادقة — Auth ✅ مُنفَّذ

> الموديول: `app/Modules/Auth` ↔ `src/features/auth`
> المسارات: `routes/api/v1/auth.php`

### POST /auth/login
**الحد:** `throttle:5,1`
**المدخلات:** `email` (مطلوب، بريد) · `password` (مطلوب)
**نجاح 200:**
```json
{
  "success": true,
  "data": {
    "token": "1|abc…",
    "user": {
      "id": 1,
      "name": "مدير النظام",
      "email": "admin@test.com",
      "role": "admin",
      "permissions": ["users.view", "users.create"]
    }
  },
  "message": null,
  "errors": null
}
```
**فشل 422:** بيانات خاطئة أو حقل ناقص — الرسالة في `errors.email[0]` بالعربية.

### POST /auth/logout
**الصلاحية:** مسجّل دخول (`auth:sanctum`)
**نجاح 200:** `data: null` و `message` تأكيد بالعربية. يُبطل التوكن الحالي فقط.

### GET /auth/me
**الصلاحية:** مسجّل دخول
**نجاح 200:** `data` هو كائن المستخدم نفسه المذكور أعلاه (بلا `token`).
**بلا توكن 401:** بالغلاف الموحّد — لا تحويل ولا HTML.

## <اسم الموديول> — `<Module>`

> **الموديول:** `app/Modules/<Module>` ↔ `src/features/<module>`
> **المسارات:** `routes/api/v1/<module>.php`
> **أعمدة البحث:** … · **أعمدة الفرز:** …

### GET /<entities>
**الصلاحية:** `<entity>.view`
**المعاملات:** المعاملات الموحّدة أعلاه + `<فلاتر خاصة>`
**نجاح 200:** `data: { items: [<الحقول>], meta: {…} }`

### GET /<entities>/{id}
**الصلاحية:** `<entity>.view` · **نجاح 200:** `data` كائن العنصر

### POST /<entities>
**الصلاحية:** `<entity>.create` · **201**
**المدخلات:** <قائمة الحقول وقواعد التحقق>

### PUT /<entities>/{id}
**الصلاحية:** `<entity>.edit` · **200**

### DELETE /<entities>/{id}
**الصلاحية:** `<entity>.delete` · **200** مع `data: null`
