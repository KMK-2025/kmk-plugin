# عقد الخدمات (API Contract)

> هذا الملف هو **المرجع الوحيد**. أي اختلاف بين الشاشات وقاعدة البيانات يُحسم بما هنا.
> يُحدَّث تلقائيًا مع كل `/build-web` — لا تحرّره يدويًا.

المسار الأساسي: `https://api.example.com/api/v1`
المصادقة: ترويسة `Authorization: Bearer <token>`

## سياسة النسخ (Versioning)
- النسخة الحالية: **v1**. كل النقاط أدناه تحتها ما لم يُذكر غير ذلك.
- **نسخة جديدة فقط عند كسر التوافق** (حذف/إعادة تسمية حقل، تغيير شكل رد). الإضافات تدخل في النسخة الحالية.
- النقاط المنقولة إلى نسخة أعلى تُوثَّق تحت عنوان `### [v2] ...` مع سطر يشرح سبب الكسر، وتبقى نسختها السابقة موثّقة حتى تُحذف رسميًا.
- حذف نسخة قديمة يُسجَّل هنا بتاريخه بعد موافقة صاحب المشروع.

## الشكل الموحّد
```
نجاح: { "success": true,  "data": ...,  "message": null }
خطأ:  { "success": false, "data": null, "message": "...", "errors": { "field": ["..."] } }
```

## رموز الحالة
`200` نجاح · `201` أُنشئ · `401` غير مسجّل دخول · `403` لا يملك صلاحية · `404` غير موجود · `422` خطأ تحقق · `429` تجاوز حد الطلبات · `500` خطأ خادم

---

## المصادقة — Auth

### POST /auth/login
**الحد:** `throttle:5,1`
**المدخلات:** `email` (مطلوب) · `password` (مطلوب)
**الرد:** `{ token, user: { id, name, email, role, permissions: [] } }`

### POST /auth/logout
**الصلاحية:** مسجّل دخول

### GET /auth/me
**الرد:** بيانات المستخدم الحالي وصلاحياته

## <اسم الموديول> — `<Module>`

> **الموديول:** `app/Modules/<Module>` ↔ `src/features/<module>`
> **المسارات:** `routes/api/v1/<module>.php`

### GET /<entities>
**الصلاحية:** `<entity>.view`
**المعاملات:** `page` · `per_page` · `search` · `sort_by` · `sort_dir` · `<فلاتر خاصة>`
**الرد:**
```json
{
  "success": true,
  "data": {
    "items": [ { "id": 1 } ],
    "meta": { "current_page": 1, "last_page": 1, "per_page": 15, "total": 0 }
  }
}
```

### GET /<entities>/{id}
**الصلاحية:** `<entity>.view`

### POST /<entities>
**الصلاحية:** `<entity>.create`
**المدخلات:** <قائمة الحقول وقواعد التحقق>

### PUT /<entities>/{id}
**الصلاحية:** `<entity>.edit`

### DELETE /<entities>/{id}
**الصلاحية:** `<entity>.delete`
