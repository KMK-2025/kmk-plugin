# نظام التصميم

> **هذا الملف فارغ عن قصد.**
>
> الإضافة تحدّد معمار النظام ولا تحدّد شكله. لا يوجد قالب جاهز ولا ألوان افتراضية —
> لأن كل مشروع له هويته.
>
> **كيف يُملأ:** ضع صورك المرجعية في `docs/design/` ثم اكتب `/صمم`.
> يستخرج القرارات من صورك، يعرضها عليك للموافقة، ثم يكتبها هنا وفي
> `frontend/src/styles/theme.css`.
>
> **أسماء المتغيرات** أدناه جزء من العقد التقني — المكونات المشتركة تشير إليها،
> فلا تُغيَّر. أما **القيم** فهي قرار تصميم حرّ.

## الإطار والتنقّل

> **لا تفترض شكلًا.** املأ ما تُظهره الصور فعلًا — وقد لا يكون هناك قائمة جانبية أصلًا.

| القرار | ما استُخرج من الصور |
|---|---|
| شكل التنقّل (قائمة جانبية / شريط علوي / تبويبات / غيره) | |
| جانب القائمة وعرضها (إن وُجدت) | |
| ارتفاع الشريط العلوي (إن وُجد) | |
| موضع اسم المستخدم وزر الخروج | |
| سلوك التنقّل على الجوال | |
| المتغيرات المقابلة | |
