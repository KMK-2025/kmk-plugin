# إنشاء مشروع جديد: $ARGUMENTS

أنت تخاطب شخصًا **لا يعرف البرمجة**. لا تعرض عليه مخرجات أوامر خام، ولا مصطلحات تقنية. اعرض تقدّمًا بلغة بسيطة، وتوقّف عند كل عقبة واشرحها بجملتين.

---

## قاعدة الاستئناف

قبل أي شيء، افحص `.setup-state` في مجلد المشروع إن وُجد.
هذا الملف يسجّل آخر مرحلة اكتملت. **إن كان موجودًا، ابدأ من المرحلة التالية له ولا تعِد ما تم.**
بعد نجاح كل مرحلة، اكتب رقمها فيه. هذا يجعل إعادة تشغيل الأمر بعد أي فشل آمنة تمامًا.

---

## المرحلة 1 — الفحص

```bash
bash "${CLAUDE_PLUGIN_ROOT}/scripts/doctor.sh"
```

اقرأ التقرير وصنّف النتيجة:

### أ) كل شيء جاهز
أخبره بجملة واحدة وانتقل للمرحلة 2.

### ب) `mysql` مفقود لكن XAMPP مثبّت
هذه أكثر حالة شيوعًا على Windows. **لا تطلب منه تثبيت أي شيء.**

1. إن كان `MYSQL_RUNNING=لا` قل:
   > "محتاج منك شغلة وحدة: افتح **XAMPP Control Panel** واضغط **Start** جنب **MySQL**. قل لي لما يصير أخضر."
   وانتظره.
2. ثم أضف المسار للجلسة الحالية بنفسك:
   ```bash
   export PATH="$PATH:<XAMPP_PATH>/mysql/bin"
   ```
3. ولتثبيته دائمًا، اسأله أولًا ثم نفّذ:
   ```bash
   echo 'export PATH="$PATH:<XAMPP_PATH>/mysql/bin"' >> ~/.bashrc
   ```
4. أعد تشغيل الفحص للتأكد.

### ج) إضافة PHP مفقودة
حدّد السطر في `PHP_INI` وأخبره:
> "في إعداد صغير ناقص بـ PHP. تحب أفعّله؟ بغيّر سطر واحد بس."

بعد موافقته: أزل `;` من أول السطر `;extension=<الاسم>`، ثم **أعد تشغيل MySQL/Apache من XAMPP** وأعد الفحص.

### د) أداة أساسية مفقودة (node أو php أو git أو composer)
**لا تثبّتها من تلقاء نفسك.** اعرض عليه الأمر واطلب إذنًا صريحًا:

| الأداة | Windows | macOS |
|---|---|---|
| Node.js | `winget install OpenJS.NodeJS.LTS` | `brew install node` |
| Git | `winget install Git.Git` | مثبّت افتراضيًا |
| PHP + MySQL | `winget install ApacheFriends.Xampp.8.2` | `brew install php mysql` |
| Composer | `winget install Composer.Composer` | `brew install composer` |

⚠️ **بعد أي تثبيت، المسارات لا تظهر في الجلسة الحالية.** قل له حرفيًا:
> "تم التثبيت ✅ بس لازم تسكّر التطبيق وتفتحه من جديد عشان يشوف الأدوات الجديدة. بعدين اكتب `/start $ARGUMENTS` مرة ثانية وبنكمل من وين وقفنا."

وأنهِ دورك هنا. **لا تحاول الالتفاف على هذا** — لن يعمل.

### هـ) الصدفة خاطئة على Windows
إن كان `SHELL_OK` سلبيًا، أخبره أن الجلسة يجب أن تعمل عبر Git Bash، وتوقّف.

## المرحلة 2 — إنشاء المشروع

اسأله عن اسم المشروع إن لم يذكره. اقترح اسمًا إنجليزيًا بحروف صغيرة وشُرَط، بلا مسافات ولا حروف عربية — **مسارات فيها مسافات تكسر الأدوات على Windows**، فاشرح ذلك بجملة واحدة إن اقترح اسمًا فيه مسافة.

```bash
bash "${CLAUDE_PLUGIN_ROOT}/scripts/setup-project.sh" <الاسم>
```

يأخذ ٥–٨ دقائق. أخبره بذلك قبل أن تبدأ حتى لا يظن أن شيئًا تعطّل، وأعطه تحديثًا عند كل خطوة كبيرة.

**إن فشل السكربت:** لا تكمل ولا ترقّع. اقرأ رسالة الخطأ، اشرح السبب بجملتين، واقترح حلًا واحدًا محددًا.

## المرحلة 3 — تثبيت الأوامر داخل المشروع

انسخ محتوى `${CLAUDE_PLUGIN_ROOT}/templates/` إلى جذر المشروع الجديد.

هذا يضع فيه: الدستور `CLAUDE.md` · الأوامر الثمانية في `.claude/skills/` · الوكلاء · إعداد المعاينة `launch.json` · قوالب الوثائق · سير النشر.

ثم انسخ الحواجز:
```bash
cp "${CLAUDE_PLUGIN_ROOT}/scripts/guard.sh"    <المشروع>/.claude/hooks/
cp "${CLAUDE_PLUGIN_ROOT}/scripts/autosave.sh" <المشروع>/.claude/hooks/
chmod +x <المشروع>/.claude/hooks/*.sh
```

> **لماذا ننسخ بدل الاعتماد على الإضافة:** ليصبح المشروع مكتفيًا بذاته. يعمل على أي جهاز حتى لو لم تكن الإضافة مثبّتة، وتبقى الأوامر بأسمائها المجرّدة `/build-web` بدل أسماء مركّبة.

## المرحلة 4 — قاعدة البيانات

1. أنشئ القاعدة باسم المشروع:
   ```bash
   mysql -u root -e "CREATE DATABASE <الاسم> CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
   ```
   إن فشلت بسبب كلمة السر، اسأله عنها ولا تخمّن. **لا تكتب كلمة السر في أي ملف يُرفع إلى Git.**

2. عدّل `backend/.env`: اسم القاعدة والمستخدم وكلمة السر والمنفذ.
3. أنشئ `frontend/.env` بسطر واحد: `VITE_API_URL=http://localhost:8000/api/v1`
4. شغّل `php artisan migrate` وتحقق من نجاحها.

⚠️ إن كانت البيئة XAMPP، فقاعدة البيانات **MariaDB** لا MySQL. اذكر ذلك مرة واحدة فقط في تقريرك النهائي — سيهم عند النشر.

## المرحلة 5 — التحقق

شغّل الواجهة والخدمات من إعداد المعاينة، وافتح الواجهة في لوحة المعاينة، وتأكد بعينك أن الصفحة تفتح والخدمات ترد.

**لا تعلن النجاح قبل أن ترى ذلك.**

## المرحلة 6 — التسليم

احذف `.setup-state`، ثم قل له:

> "مشروعك جاهز ✅
>
> **صار عندك:**
> · مكان للشاشات ومكان للمعلومات، ومربوطين ببعض
> · قاعدة بيانات فاضية جاهزة
> · حفظ تلقائي — أي غلطة بترجع بأمر واحد
>
> **أوامرك من الآن:**
> `/idea` نحكي عن نظامك · `/apply-design` تصاميمك · `/build-web` قسم جديد · `/test` تشوفه · `/share-link` تبعته لحدا · `/deploy` يطلع للناس · `/fix` إذا وقف شي · `/go-back` ترجع لورا
>
> ابدأ بـ **`/idea`**."

ثم اسأله سؤالًا واحدًا:
> "تحب يكون لنظامك تطبيق على الجوال كمان؟ نقدر نضيفه الآن أو بأي وقت بعدين بأمر `/add-mobile`."

إن قال نعم الآن، نفّذ خطوات `/add-mobile` من مرحلتها الأولى. إن قال لاحقًا أو لا، لا تذكره ثانية.
