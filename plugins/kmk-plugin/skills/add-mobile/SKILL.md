# إضافة تطبيق جوال للمشروع

أنت تخاطب شخصًا **لا يعرف البرمجة**. قل "التطبيق" و "الجوال" — لا Flutter ولا SDK ولا APK. اعرض تقدّمًا بلغة بسيطة وتوقّف عند كل عقبة واشرحها بجملتين.

شغّل هذا الأمر من داخل مجلد مشروع فيه `backend/` و `CLAUDE.md`. إن لم يكن كذلك قل له أن يفتح مجلد مشروعه أولًا، أو ينشئ مشروعًا بـ `/start`.
إن وُجد `mobile/` مسبقًا فالتطبيق مضاف: قل له ذلك واقترح `/build-mobile <اسم القسم>`.

---

## المرحلة 1 — فحص بيئة الجوال

```bash
bash "${CLAUDE_PLUGIN_ROOT}/scripts/doctor-mobile.sh"
```

### أ) `flutter` و `java` و `adb` كلها موجودة
انتقل للمرحلة 2.

### ب) شيء منها مفقود
قل له:
> "جهازك محتاج تجهيز مرة وحدة عشان يقدر يبني تطبيقات جوال. بياخذ **ربع ساعة لنص ساعة** وبينزّل حوالي 4 جيجا. أبدأ؟"

بعد موافقته شغّل في الخلفية وأعطه تحديثًا كل بضع دقائق:
```bash
bash "${CLAUDE_PLUGIN_ROOT}/scripts/setup-mobile.sh"
```
- **إن فشل:** لا ترقّع. اقرأ الرسالة، اشرح السبب بجملتين، واقترح حلًا واحدًا.
- **إن طبع `DEV_MODE=غير مفعّل`** (Windows): هذه خطوة يدوية لا تستطيعها أنت. قل له: "افتح الإعدادات ← النظام ← للمطوّرين ← فعّل «وضع المطوّر»، وقل لي لما تخلص." وانتظره.
- أعد تشغيل الفحص للتأكد قبل المتابعة.

### ج) `IOS_BUILD=عبر CI فقط`
اذكر له مرة واحدة: "التطبيق بيشتغل على أندرويد من جهازك مباشرة. نسخة الآيفون بتنبني على الإنترنت لما تحتاجها — لأن آبل ما بتسمح ببناء تطبيقاتها إلا على أجهزتها."

## المرحلة 2 — سؤالان فقط

1. **اسم الشركة أو النشاط بالإنجليزية** (كلمة واحدة، مثل `acme`). يُشتق منه معرّف التطبيق `com.acme`. اشرح: "هذا زي رقم هوية للتطبيق، ما بيتغيّر بعدين."
2. **اسم التطبيق الذي يظهر تحت الأيقونة** (بالعربية، مثل «عيادتي»).

اسم التطبيق الداخلي: اسم مجلد المشروع بحروف إنجليزية صغيرة وشرطة سفلية بدل أي رمز آخر (مثل `clinic` أو `my_shop`). لا تسأله عنه.

## المرحلة 3 — الإنشاء

يأخذ ٣–٦ دقائق. أخبره قبل أن تبدأ.
```bash
bash "${CLAUDE_PLUGIN_ROOT}/scripts/add-mobile.sh" . <app_name> com.<company>
```
**إن فشل السكربت:** لا تكمل ولا ترقّع. اشرح السبب واقترح حلًا واحدًا.

ثم:
1. `cd backend && php artisan migrate`
2. ضع اسم التطبيق العربي في `appTitle` داخل `mobile/lib/shared/l10n/app_ar.arb` (ومقابله الإنجليزي في `app_en.arb`)، وفي `android:label` داخل `mobile/android/app/src/main/AndroidManifest.xml`.
3. إن كان `docs/design-system.md` معبّأً، طابق `mobile/lib/shared/theme/app_theme.dart` معه.
4. شغّل بوابة الجوال والخدمات وتأكد من مرورهما:
```bash
. ~/.kmk-mobile-env 2>/dev/null; cd mobile && flutter analyze && dart format --set-exit-if-changed lib test && flutter test
cd backend && ./vendor/bin/pint && ./vendor/bin/phpstan analyse && php artisan test
```

## المرحلة 4 — الهاتف

```bash
bash "${CLAUDE_PLUGIN_ROOT}/scripts/doctor-mobile.sh"
```
- **لا يوجد جهاز:** "شبّك جوالك الأندرويد بالكابل. لو أول مرة: الإعدادات ← حول الهاتف ← اضغط «رقم الإصدار» 7 مرات. بعدين الإعدادات ← خيارات المطوّر ← فعّل «تصحيح USB»." وانتظره.
- **ينتظر الموافقة:** "طلعت رسالة على شاشة جوالك — اضغط «السماح»."
- **ليس معه هاتف الآن:** لا بأس. أنهِ المرحلة 6 وقل له أن يكتب `/test mobile` عندما يوصله.

## المرحلة 5 — التحقق على الهاتف

شغّل `الخدمات` من إعداد المعاينة، ثم:
```bash
. ~/.kmk-mobile-env 2>/dev/null
adb reverse tcp:8000 tcp:8000
cd mobile && flutter run -d <serial>
```
أول تشغيل يأخذ بضع دقائق. بعد أن يفتح، التقط لقطة وافحصها بنفسك:
```bash
. ~/.kmk-mobile-env 2>/dev/null; mkdir -p .claude/tmp && adb exec-out screencap -p > .claude/tmp/screen.png
```
**لا تعلن النجاح قبل أن ترى شاشة الترحيب العربية في اللقطة.**
