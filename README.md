# سوق إضافات: kmk-marketplace

إضافة واحدة تُدير بناء أنظمة إدارية عربية RTL بأمر واحد، موجّهة لمستخدمين لا يعرفون البرمجة.

## التثبيت

```
/plugin marketplace add KMK-2025/kmk-plugin
/plugin install kmk-plugin@kmk-marketplace
```

## الاستخدام

```
/ابدأ متجري
```

يفحص البيئة، يصلح ما ينقص، ينشئ مشروعًا **يعمل فعلًا**، ويثبّت داخله أحد عشر أمرًا عربيًا:

`/فكرة` · `/صمم` · `/ابن` · `/جرب` · `/شارك` · `/انشر` · `/اصلح` · `/تراجع` · `/وين-وصلنا` · `/بيانات` · `/حدث`

## المبدأ المعماري الأول: المعمار محدَّد والتصميم حرّ

| الإضافة تحدّده (ثابت لكل مستخدم) | `/صمم` يحدّده (مختلف لكل مشروع) |
|---|---|
| بنية الموديولز وحدودها | تخطيط الصفحات |
| عقد الخدمات وغلاف الردود | شكل التنقّل: قائمة؟ شريط؟ تبويبات؟ |
| المصادقة والجلسة وحماية المسارات | الألوان والخطوط والمسافات |
| الصلاحيات والزرع والاختبارات والأمان | شكل كل مكوّن |

المشروع الجديد يفتح **بلا تنسيق — وهذا نجاح لا عطل.** المستخدم يضع صوره في
`docs/design/` ثم `/صمم` يبني الهوية منها. لا أحد يحصل على قالب شخص آخر.

## المبدأ المعماري الثاني: الإضافة تشحن السكربت، والسكيل يشغّله

الإنشاء حتمي (سكربت واحد بترتيب ثابت وملف قفل مثبّت)، والتشخيص والتعامل مع الأعطال
محادثة. هذا يمنع اختلاف الناتج بين متدرب وآخر، ويجعل الفشل يقع في نقطة واحدة معروفة
بدل مشروع نصف مبني. والسكربت **آمن لإعادة التشغيل**: يسجّل ما أتمّه ويكمل من حيث توقّف.

**الأوامر تُنسخ داخل المشروع ولا تبقى في الإضافة.** فائدتان: المشروع يعمل على
أي جهاز بلا الإضافة، والأوامر تُكتب بأسمائها المجرّدة `/ابن` بدل صيغة مركّبة.

## البنية

```
.claude-plugin/marketplace.json     ← فهرس السوق
plugins/kmk-plugin/
├── .claude-plugin/plugin.json      ← تعريف الإضافة
├── skills/ابدأ/SKILL.md            ← الأمر الوحيد في الإضافة
├── scripts/
│   ├── doctor.sh                   ← فحص البيئة (XAMPP، المنافذ، الإصدارات)
│   ├── setup-project.sh            ← إنشاء المشروع — حتمي وقابل للاستئناف
│   └── switch-to-latin.sh          ← تبديل أسماء الأوامر إن تعذّرت العربية
├── starter/                        ← الأساس التقني: كود حقيقي يعمل، بلا تصميم
│   ├── VERSION
│   ├── frontend/                   ← شجرة كاملة + package-lock.json مثبّت
│   └── backend/                    ← يُنسخ فوق Laravel بعد إنشائه
└── templates/                      ← يُنسخ إلى جذر كل مشروع جديد
    ├── CLAUDE.md
    ├── .claude/{skills,agents,hooks,launch.json,settings.json}
    ├── docs/                       ← spec · api-contract · design-system (فارغ)
    └── .github/workflows/
```

## التحديث

عدّل هنا وادفع إلى GitHub، والمستخدمون يحدّثون بـ `/plugin marketplace update`.

⚠️ المشاريع المُنشأة سابقًا **لا تتحدث تلقائيًا** — نسخها مجمّدة لحظة الإنشاء، ويسجّل
كل مشروع نسخة الأساس التي وُلد بها في `.kmk-shell-version` ووسم `shell-x.y.z`.
لتحديث مشروع قائم، أعد نسخ `templates/.claude/skills/` فوقه.
